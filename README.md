# Zerodha Clone - Trading Dashboard

A full-stack trading dashboard inspired by Zerodha. This application enables users to manage stock holdings, track orders, monitor watchlists, and visualize portfolio data through interactive charts.

## Live Demo

🔗 https://zerodha-clone-dashboard-gilt.vercel.app/

## Features

### Authentication

* Secure Login and Registration
* JWT-based authentication
* Cookie-based session management

### Portfolio Management

* View holdings in dynamic tabular format
* Track positions and orders
* Real-time portfolio updates after stock purchases

### Watchlist

* Persistent watchlist across pages
* Interactive stock cards
* Hover-based Buy Action Window
* Quick access to trading actions

### Data Visualization

* Holdings represented through bar charts
* Watchlist represented through doughnut charts
* Interactive dashboard analytics

### Trading Workflow

* Buy stock functionality
* Order tracking
* Holdings management
* Position management

## Tech Stack

### Frontend

* React.js
* JavaScript
* Axios
* Chart.js

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* JWT Authentication
* HTTP Cookies

## Database Collections

* Users
* Holdings
* Positions
* Orders

## Architecture

The project is divided into three independent modules:

1. Landing Page Application
2. Trading Dashboard Application
3. Backend API Server

This separation allows independent development and deployment of frontend and backend services.
